## Inside GitKraken Desktop

GitKraken Desktop is a local Windows git client with a named kraken desk, a short workspace list, and a clear last handoff. It does not try to replace the rest of the PC. It sits beside a repo you already keep and holds only the graph that is open now.
The layout stays small on purpose: one desk, one list, one path back. Extra graphs wait for their own title. GitKraken Desktop starts with a local profile and does not need a complex account system.
